# NFLLM DOS 0.1 Beta

This is the first DOS binary release of NFLLM. The downloadable ZIP contains
`NFLLM.EXE`, the project license and notices, a checksum, and these usage notes.
The source code is available in the repository tag `v0.1.0-beta`.

The included `NFLLM.EXE` is 52,420 bytes with SHA-256
`102A75685519294540BF0FB8E6B411F6349318FD846476F95928C788D08DE285`.

## Run

The program requires a compatible DOS/4GW runtime and a GGUF v3 model using
F32 tensors and the `llama` architecture. Neither the runtime nor model weights
are included in this ZIP.

```dos
NFLLM.EXE C:\TINY1M.GGF -p "Tom and Jerry are " -n 1
```

## Tested configuration

The binary was tested in 86Box 6.0 with an AMD Am486DX4 at 100 MHz, 96 MiB RAM,
NF-DOS 5 build 5.01.3314, DOS version 7.10, and DOS/4GW runtime 1.97. The tested
models were TinyStories 260K F32 and TinyStories 1M F32; the ZIP does not
include them.

Standalone MS-DOS, other GGUF architectures, quantized models, and the full
upstream `llama.cpp` runtime are not verified. See the repository README and
`docs/SOURCE_PROVENANCE.md` for scope and provenance status.
