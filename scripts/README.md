# Verification scripts

These PowerShell helpers were used with a separate Windows workspace containing
NF-DOS disk images and an 86Box installation. That workspace is not included in
this repository. The scripts expect an isolated test-disk clone and use safety
checks to avoid editing the original disk.

Review each script and provide the correct workspace paths before running it.
The scripts do not create a general-purpose 86Box environment from this source
repository alone.
