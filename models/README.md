# Test models

Model weights are not stored in this repository. Obtain each model from its
own source and review its license before use or redistribution.

The verified TinyStories 1M F32 test file was 3,754,048 bytes and had SHA-256
`60FA2675B0531735C9724C9FCB871BAA6E40594F451D1454981034BE47D025D4`. The
handoff recorded its source as the
[shibatch/tiny1m model card](https://huggingface.co/shibatch/tiny1m), whose
license field was reported as MIT. The TinyStories 260K F32 test file is also
omitted; its redistribution terms were not established in the handoff.
